# Conventions and generated contracts

Use typed Python functions and closed Pydantic v2 models with extra fields forbidden. Runtime configuration/envelope/result fields use snake_case. Existing model-tooling and native decision wire fields use their declared camelCase names directly. Neither boundary accepts a second alias spelling. Ordinary Python functions and locals use snake_case. Inputs are strictly validated, including bool versus int. Owned structured boundaries use explicit types; finite JSON payload leaves stay open and are validated against configured schemas. Third-party internals are narrowed inside adapters.

Canonical typed classes and generated schemas define public shapes. Generate runtime and native decision schemas under `schemas/foliqant/` from `src/foliqant/contracts/` and `src/foliqant/decisions/`; generate model-only schemas under `model/schemas/` from `model/src/foliqant_model/`. Generation is one-way, deterministic, sorted and checked for drift. No handwritten duplicate schema files. The representation catalog owns permitted backend/config/log projections. Business validation, filesystem/process supervision, adapter calls and metrics remain handwritten. Unknown versions are rejected rather than guessed. Explicit model-data migration publishes new immutable descendants; it is not generic artifact or runtime-config migration.

Keep core data/artifact commands free of import-time MLX dependencies. Prefer small cohesive modules, no generic global helpers package. Use docstrings and examples for non-obvious public functions. Source code must pass strict mypy, Ruff and meaningful pytest checks. Do not silence broad type/lint checks to accommodate avoidable weak contracts.

Schema and contract checks must include unknown fields, missing versus null fields, invalid union combinations, bool-as-number rejection, unsafe paths, exact hash/identity validation and cross-field lineage rules. Publication and financial/regulatory fitness are outside local wheel acceptance.
