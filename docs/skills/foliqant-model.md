# Foliqant model operating skill

The [foliqant-model skill](https://github.com/sebastianwessel/foliqant/blob/main/skills/foliqant-model/SKILL.md) helps an agent
operate setup, curation, training, customization, evaluation, calibration, audit,
export and artifact verification.

It uses current CLI help and the public model guides. Its focused references
cover immutable resume, offline projection/migration, recovery, source rights
and exact model ancestry. It does not cover the runtime Python workflow API or
grant permission to upload data, use paid compute or accept gated terms.

Start with [model setup](../getting-started/setup.md). For decision-data work,
use [native decision data](../guides/native-decision-data.md). Runtime pipelines
and golden-case evaluations use the [foliqant skill](foliqant.md).
